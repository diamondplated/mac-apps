# Mac Tools 1.3.1

Mac Tools checks installed apps against the signing identity of its bundled payload before managing them. Uninstall disables and confirms launch-at-login registration before moving an app to the Trash.

Latent 0.3.2 bounds enhancement memory, preserves useful cache entries when an image is too large to cache, and notices newly installed enhancement models. Phone pairing isolates failed attempts by peer, the listener binds to a physical LAN address, and archive validation rejects ambiguous 7z listings. Archive extraction retains a process lease through crashes and cancellation so later cleanup reclaims inactive copies without deleting a live extractor’s directory. Conversion scripts verify upstream source and checkpoint provenance. The viewer now uses a floating-point Metal display path for HDR and wide-gamut images, with a fallback when Metal is unavailable. The app bundle also includes a read-only Quick Look preview extension.

Sift 2.0.3 asks before downloading Excel or Delta support at first use and does not fetch those extensions at launch. It refuses strict sessions when hardening fails, retains the original view when staging cannot count or record its copy, and isolates fallback instances' downloaded files from the shared cache sweep. Its loopback test server preserves socket ownership through shutdown to prevent descriptor reuse races.

Sift now uses DuckDB 2.0 with remeasured query/network facts, limits its new asynchronous I/O worker pool without reducing query parallelism, and keeps new staged stores readable by the previous DuckDB 1.5.6 engine.

Sift closes session admission and drains in-flight work before releasing its store. App termination waits for that drain, and test/verifier scopes own their sessions through cleanup to prevent queries racing database runtime teardown.
