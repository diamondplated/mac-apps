Mac Tools now brings four everyday apps and six built-in utilities together in a refreshed native interface.

- **ScrollSplit:** Set mouse-wheel direction and speed while preserving continuous scrolling.
- **LinkRoutes:** Route domains to browsers and supported profiles, with a route preview.
- **Permission Doctor:** Check installed copies, signatures, and each tool's permission evidence.
- **Startup Detective:** Inspect startup services and identify missing targets.
- **SleepPeek:** See current sleep blockers and recent recorded wake events.
- **SpaceWatch:** Measure local folders, compare growth, and review selected files before moving them to Trash.
- **HogWatch:** Inspect CPU and memory use and watch for sustained activity.
- **NetPeek:** Check interfaces, routing, DNS, and website response headers.

All four apps have settings in Mac Tools. Unsaved link-rule edits survive navigation, and updates preserve enabled launch-at-login registrations. ScrollSplit's input access and LinkRoutes' default-browser registration require explicit setup in their native settings.
