Three new things: a window switcher, Dock clicks that do something, and LinkRoutes rules that depend on where a link was clicked. After updating Mac Tools, click Update All in the Library to get DockPeek 1.3.0 and LinkRoutes 1.2.0.

- **Switch windows with ⌥Tab (DockPeek).** Hold Option and press Tab to see every open window with a live thumbnail, most recent first. Tab, ⇧Tab and the arrow keys move the highlight; release Option to switch; Esc cancels. A quick ⌥Tab jumps straight to the window you were in before. This is on by default. A few apps use ⌥Tab themselves, for example to insert a tab inside a table cell in Pages or Word; the switcher takes it over while it is on. Turn it off on DockPeek's page in Mac Tools.
- **Dock clicks (DockPeek), each off until you turn it on:** click the front app's Dock icon to hide it; scroll on an icon to cycle that app's windows; middle-click an icon for a new window. Every other click on the Dock behaves as before.
- **Rules by source app (LinkRoutes).** A rule can now name the app a link was clicked in, so links from one app can open in one browser profile and links from another app in a different one. Leave the website empty to cover every link from that app. Choose the app from the rule's menu on LinkRoutes' page.
- **Link cleaning (LinkRoutes).** Known tracking parameters such as `utm_source` and `fbclid` are now removed before a link opens. This is on by default and changes the links your browser receives; turn it off on LinkRoutes' page. A second option, off by default, opens the real destination of wrapped links from Outlook Safe Links, Google, Facebook and Slack. Outlook Safe Links let an organisation scan a link first, and unwrapping skips that. Cleaning never contacts a server.
- **What DockPeek looks at:** to notice ⌥Tab and Dock clicks, DockPeek watches key presses and, for the Dock actions you turn on, mouse events near the Dock. It reads which key or button was used and nothing else, stores nothing, and removes the watcher when a feature is off. It needs the Accessibility access it already has.
- **Limits in this first version:** a window on another Space is listed, but choosing it brings its app forward rather than that exact window. The shortcut is fixed at ⌥Tab.
