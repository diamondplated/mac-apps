Ten new things across the suite, and one new app. After updating Mac Tools, click Update All in the Library, and install StayLit from there if you want it. Everything that changes how your keyboard, mouse, windows or files behave starts switched off.

- **New app: StayLit.** Keep the Mac awake from its menu bar menu: now, for 30 minutes to 2 hours, or while a chosen app is running. It says why the Mac is awake, and lets it sleep on battery below 20 percent. It can also make the brightness and volume keys work on an external display that macOS does not control; both switches are on its page in Mac Tools and start off.
- **ScrollSplit fixes more of the mouse.** Three switches on its page: **Smooth scrolling** turns each wheel notch into a short glide; **Side buttons go back and forward** makes buttons 4 and 5 work in apps that ignore them; **Turn off pointer acceleration for mice** makes a mouse move the pointer linearly while the trackpad keeps its normal feel.
- **ScrollSplit keyboard overrides.** **Hold ⌘Q to quit** stops a stray ⌘Q closing an app. **Caps Lock is a Hyper key** makes Caps Lock held with another key act as ⌃⌥⇧⌘; Caps Lock no longer locks capitals while this is on, and an optional second switch makes a lone tap send Escape. Two shortcuts you assign yourself: **Paste as Plain Text**, which works in every app and reads the clipboard only when you press it, and **Mute or Unmute Microphone**, which shows a crossed-out microphone in the menu bar while muted.
- **DockPeek remembers window layouts.** It keeps track of where every window was for each monitor setup and puts them back when displays change. Save Window Layout and Restore Window Layout are in its menu bar menu; the automatic switch is on its page. Window titles are stored on your Mac only.
- **LinkRoutes routes files.** A file rule sends a file type to a chosen app depending on its folder, so the same kind of file can open in different apps in different places. LinkRoutes becomes the default app for a type only while that type has a rule, opens anything that matches no rule in the app that was the default before, and hands every type back with Stop Routing Files. Mac Tools will not uninstall LinkRoutes while it still owns a file type.
- **ScreenWren records.** Record Region captures an area you choose after a 3-2-1 countdown, with no audio of any kind. Trim it, then export as MP4 or GIF at original size, half size, or a width you pick. Recordings stop at five minutes.
- **ScreenWren picks colours.** Pick Colour shows the system loupe and copies the hex value of the pixel you click. Both new ScreenWren commands can be given shortcuts on its page.
- **Sift previews data files in Finder.** Select a CSV, TSV, Parquet, JSON or NDJSON file and press Space to see a table with its row count, columns and types. Open Sift once after updating so macOS finds the preview. The preview reads only the file you selected, never uses the network, and gives up after two seconds rather than stall Finder.
- **Latent groups bursts.** A new Bursts choice in the filter bar stacks near-identical shots taken seconds apart and marks the sharpest, or the one with the best faces. Return keeps the suggested frame and rejects the rest; ⇧Return keeps the one you are looking at. It only sets pick and reject, and ⌘Z undoes it.
- **First versions, so expect tuning.** None of the features above that sit in front of the keyboard, mouse, displays or default apps could be tried with real input before release. If one misbehaves, its switch turns it off completely.
