A fix release for ScreenWren and DockPeek, now that macOS 27 is out.

- **ScreenWren 0.5.1:** Old editor windows no longer jump in front of what you're capturing while you pick a window or area.
- **ScreenWren on macOS 27:** The editor can shrink to narrow widths again instead of getting stuck at its widest toolbar layout.
- **ScreenWren security:** Other apps and scripts can no longer make ScreenWren take a screenshot and save it somewhere without you asking. A testing-only launch option did this in shipped builds; it's now left out of them.
- **DockPeek:** A preview that has already faded out closes right away instead of lingering as an invisible window on macOS 27.
