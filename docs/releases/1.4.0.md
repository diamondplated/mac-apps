Every app in the suite has been cut back and rebuilt to look and behave like a native Mac app. This is the first published release since 1.2.1, so it also carries everything prepared for 1.3.0 and 1.3.1.

- **After this update, grant DockPeek Accessibility and Screen Recording once more.** DockPeek is now signed with Mac Tools' own certificate and hardened runtime. Before, macOS would hand DockPeek's access to any app that claimed to be DockPeek. Use System Settings › Privacy & Security, or the items in DockPeek's menu bar menu.
- **Mac Tools is one page per app.** The Library lists six apps with one action each: Install, Update, or Open. Each app's page holds its settings, the macOS permissions it needs, and its version. Changes apply as you make them. Update options and the install location moved to Mac Tools › Settings (⌘,).
- **The six built-in utilities are gone:** Permission Doctor, Startup Detective, SleepPeek, SpaceWatch, HogWatch, and NetPeek. What they stored is removed. Permission status now sits on each app's page, and shows only what the running app itself reports.
- **Latent and Sift join Mac Tools.** Install, update, open, and remove them from the Library. If you already have either one, Mac Tools updates that copy in place. Latent needs a Mac with Apple silicon.
- **Settings in every menu bar app opens its page in Mac Tools.** ScrollSplit and LinkRoutes no longer have settings windows of their own. Turn ScrollSplit on, or make LinkRoutes the default browser, from each app's menu bar menu. Both offer setup once on first launch.
- **DockPeek 1.2.0:** a plain menu, and a finished preview panel with consistent corners, light mode support, and eased hover and resize.
- **ScreenWren 0.6.0:** the editor has one row of tools and one Copy button. Blur, structured text preview, combining recents, timed capture, "Save PNG Directly", and the Capture Preferences window are removed. Panels fade in and out, and colours follow light and dark mode while a window is open.
- **Latent 0.6.0:** a real menu bar with every shortcut, a five-group toolbar, and the enhancement panel rebuilt as an inspector. The 4× and SwinIR upscale choices, the tile-size slider, Vim-style marks, and the nine label chips are removed; labels are one menu. Also from earlier builds: MKV and AVI playback, HDR and wide-gamut display, bounded enhancement memory, a Quick Look preview extension, and upright previews.
- **Sift 2.1.0:** Edit › Copy As writes the current view as pandas, Polars, DuckDB, or SQL. Column headers have a menu for sorting and filtering. The sidebar is the table list; paste a path or URL with File › Open Location (⌘L). The SQL console follows light and dark mode, and ⌘S no longer toggles the sidebar. Also from earlier builds: DuckDB 2.0, and Sift asks before downloading Excel or Delta support.
- **Safer installs:** Mac Tools checks an installed app against the signing identity of its bundled copy before managing it, and Uninstall turns off launch at login before moving an app to the Trash.
